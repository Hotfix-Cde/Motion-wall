# MotionWall

A minimal Android live wallpaper app for setting videos from local storage as your wallpaper.

## Features
- Pick local videos with Android's document picker
- Preview selected video
- Mute/unmute
- Auto / portrait / landscape orientation preference
- Crop / fit preference
- Local/offline-first
- Native Android live wallpaper service
- Battery-conscious pause/resume
- Reusable GitHub Actions APK build + GitHub Release workflow

Android 9+ (API 28+).
